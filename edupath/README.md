# Edupath Mobile App 🎓

Welcome to the **Edupath** React Native mobile application directory.

For comprehensive documentation, project structure, and feature overview, please refer to the [Root README](../README.md).

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run data validation checks
npm run validate:data

# 3. Start Expo development server
npx expo start -c
```

## Build APK

To generate an installable Android APK via EAS:

```bash
eas build --profile preview --platform android
```
